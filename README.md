# Dhrati Sharma Portfolio

A responsive single-page portfolio built with React, Vite, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

The local site runs at `http://localhost:3000/` when started with the configured
preview command used in this workspace.

## Production build

```bash
npm run build
```

Vite writes the static production site to `dist/`, which can be deployed to
Cloudflare Pages with `npm run build` as the build command and `dist` as the
output directory.

Place the final résumé at `public/resume.pdf` to activate the résumé link.
